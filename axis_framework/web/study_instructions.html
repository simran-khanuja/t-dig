Before you start

Please read this page. You can open it again at any time with the Instructions button at the top of every screen.

What you will do

{MODEL_NOTE}

You will make {N} sets of images. For each set:

  1. Write a prompt describing an image you would like to see, and look at the four images the system makes for it.
  2. If you would like more variety, say in your own words what should differ between the images (the axis, for example “dog breed” or “time of day”). Choose Generate new for a fresh set that varies in that way, or Edit these to keep the current images and add the variation. The slider asks for more or less variety.
  3. Rate the result: did the images vary in the way you asked, and do they still match your prompt?

At the end there is a short questionnaire.

What an axis is

An axis names one thing that should be different from image to image, while everything else in your prompt stays the same. Put anything that all images should show into the prompt, not the axis.
